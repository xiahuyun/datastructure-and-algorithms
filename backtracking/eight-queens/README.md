# backtracking/eight-queens — 八皇后（递归回溯）

用递归回溯解决经典的八皇后问题：在 8×8 棋盘上放 8 个皇后，使它们**互不攻击**（即任意两个皇后不在同一行、同一列、同一条对角线上）。

## 运行方式

```bash
cd backtracking/eight-queens
go run main.go
```

预期输出（共 92 个解，这里只展示前 3 个 + 第一个解的棋盘）：

```

  解 2: [0 5 7 2 6 3 1 4]
  解 3: [0 6 3 5 7 1 4 2]

第一个解的棋盘:
Q.......

.......Q
.....Q..
..Q.....

...Q....
```

## 棋盘如何表示

用一个一维数组 `queens`，`queens[i]` 表示**第 i 行的皇后放在第几列**。这样：

- 天然满足「不同行」（每行只放一个，就是数组里一个元素）；
- 只需再检查「不同列」和「不同对角线」两件事。

## 冲突判断（isValid）

在第 `row` 行第 `col` 列放皇后时，逐个看前面已放好的皇后 `i`：

- **同列**：`queens[i] == col`
- **同对角线**：行列差相等，即 `row - i == |col - queens[i]|`

任一命中即冲突。

## 回溯思路（backtrack）

1. 从第 0 行开始，一行一行地放。
2. 在当前行依次尝试每一列，能放（`isValid` 通过）就放下，递归进入下一行。
3. 如果某一行所有列都放不下，或递归到底发现走不通，就**回退到上一行换下一列**继续试。
4. 放到第 `n` 行（行 `row == n`）时，说明 8 个皇后都放好了，记下一个解。

核心代码只有这几行：

```go
for col := 0; col < n; col++ {
    if isValid(queens, row, col) {
        queens[row] = col  // 放下
        backtrack(row + 1) // 递归到下一行
        // 回溯：无需显式撤销，下一轮循环会直接覆盖 queens[row]
    }
}
```

## 复杂度

- 理论上最坏是 `O(n!)`（每行 n 种选择），靠 `isValid` 剪枝实际远小于此。
- 空间：`O(n)`（递归栈深度 + 当前棋盘状态）。

## 关键点

- **回溯 = 递归 + 剪枝**：递归负责「一层层试」，`isValid` 提前砍掉不可能的分支，避免暴力枚举全部 `n!` 种摆放。
- 解的个数是固定的：八皇后共有 **92** 个解（若把旋转、镜像视为相同则只有 12 个独立解）。
- 改 `const n` 的值就能变成 N 皇后。
