# 236. 二叉树的最近公共祖先（Lowest Common Ancestor of a Binary Tree）

> https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/

## 题目描述

给定一个二叉树，找到该树中两个指定节点的最近公共祖先（LCA）。
最近公共祖先的定义：对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，
满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。

示例树：

```
        3
      /   \
     5     1
    / \   / \
   6   2 0   8
      / \
     7   4
```

- 输入 `p = 5, q = 1` → 输出 `3`（分居根两侧）
- 输入 `p = 5, q = 4` → 输出 `5`（p 是 q 的祖先）

## 核心洞察：答案就是两条路径的"分叉点"

把"根→p"与"根→q"两条路径画出来：它们**上半段重合，到某一点才分开**。
那个分叉点就是最近公共祖先——分叉点之上两条路径共享路线，分叉点之下各走各的。

于是问题转化为：**站在哪个节点上，能断定自己就是分叉点？**
站在任一节点观察 p、q 的位置，只有四种情况：

1. 都在左子树 → 答案在深处，问题缩小为左子树里的子问题；
2. 都在右子树 → 同上；
3. 分居两侧 → 两条路径必经当前节点 → **当前节点就是答案**；
4. 当前节点就是 p（或 q）→ 由"节点可作为自己的祖先" → **当前节点就是答案**。

情况 1、2 暗示递归缩小；情况 3、4 就是递归的出口判定。

## 递归解法（lowestCommonAncestorRecursive）

先定义递归函数的**返回值语义**（本题灵魂）：每个节点向父节点"汇报"
自己子树里 p、q 的寻找结果——

| 子树中的情况 | 返回值 |
|---|---|
| p、q 都没有 | `nil` |
| 只找到 p | `p` |
| 只找到 q | `q` |
| p、q 都在（或已出答案） | 它们的 LCA |

每个节点合并左右两份报告：两边都非空 ⟺ 分居两侧 ⟺ 我是分叉点；
单边非空 ⟺ 都在那侧 ⟺ 报告原样上传。

**容易踩的坑**：p 是 q 的祖先时，碰到 p 就立即返回、不再下钻。
q 的存在性由题目保证，"p 的子树里有没有 q"不影响答案仍是 p。

时间 O(n)：每个节点至多访问一次；空间 O(高度) 递归栈，斜树最坏 O(n)。

## 路径解法（lowestCommonAncestorPath）

朴素而直观：先回溯求出"根→p"、"根→q"两条完整路径，
再从头逐位比对，**最后一个相同节点**即答案。

它和递归解法本质相同：递归解法把"存两条路径再比对"压缩成
"边递归边把比对结果往上带"——信息不显式存储，而是藏在返回值里逐层上传；
本解法则把两条路径完整摊开在桌面上从头对齐。

时间 O(n)，空间 O(n)（两条路径 + 回溯栈）。

## 复杂度对比

| 方案 | 时间 | 空间 |
|---|---|---|
| 递归 | O(n) | O(高度)，最坏 O(n) |
| 路径 | O(n) | O(n) |
