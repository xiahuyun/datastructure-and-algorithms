# graph — 广度优先搜索（BFS）最短路径

用 `main.go` 演示在**无向无权图**上通过广度优先搜索（BFS）寻找两点之间的最短路径。

## 运行方式

```bash
cd graph
go run main.go
```

预期输出：

```
从 A 到 G 的最短路径: [A B D E G]
最短边数: 4
```

## 示例图

```
    A -- B
    |    |
    C -- D -- E
         |    |
         F -- G
```

图用邻接表表示（`map[string][]string`），A 起点、G 终点。

## 算法思路

1. 从起点出发，按「层」向外扩展：先访问距离 0 的起点，再访问距离 1 的邻居，再距离 2……
2. 用队列保存待访问节点，保证「先入先出」的自然分层顺序。
3. 用 `parent` 记录每个节点由谁访问到，最后从终点回溯重建路径。
4. 用 `dist` 记录起点到每个节点的最短边数。

关键性质：在**每条边权重相同（无权）**的图上，BFS 第一次访问到某个节点时走过的边数就是它的**最短距离**。

## 复杂度

- 时间：`O(V + E)`，每个节点和每条边都访问一次。
- 空间：`O(V)`，队列 + `parent` + `dist`。

## 说明

- BFS 只适用于**无权图**（或所有边权重相等）的最短路径。
- 若边带不同权重，最短路径要用 Dijkstra 算法。
- 本示例中的图是连通图；若两点不连通，`BFS` 返回 `ok=false`。
