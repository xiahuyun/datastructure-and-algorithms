# graph/dfs — 深度优先搜索（DFS）

用 `main.go` 演示在无向图上做深度优先搜索（DFS），包含三个函数：

- `DFSRecursive` — 递归版遍历
- `DFSIterative` — 迭代版遍历（用栈模拟递归）
- `DFSFindPath` — 从起点走出一条到终点的路径（**不保证最短**）

## 运行方式

```bash
cd graph/dfs
go run main.go
```

预期输出：

```
递归 DFS 访问顺序: A B D C E G F
迭代 DFS 访问顺序: A B D C E G F
DFS 找到的一条路径（不保证最短）: [A B D E G]
```

## 示例图

与 `graph/` 下的 BFS 示例是同一张图，方便对照：

```
    A -- B
    |    |
    C -- D -- E
         |    |
         F -- G
```

## 算法思路

1. 从起点出发，**一条路走到黑**：能往前走就一直往前走。
2. 走到无路可走（所有邻居都访问过）时，**回退**到上一个分叉点，再换一条没走过的路。
3. 递归实现：函数调用栈自动帮你记下「回退点」。
4. 迭代实现：用一个显式 `stack` 模拟递归调用栈。

递归和迭代两条实现输出的访问顺序完全一致，可以对照理解。

## 复杂度

- 时间：`O(V + E)`，每个节点和每条边访问一次。
- 空间：`O(V)`，递归栈（或显式栈）最深可达节点数。

## 与 BFS 的区别

| | DFS（深度优先） | BFS（广度优先） |
| --- | --- | --- |
| 走法 | 一条路走到黑再回头 | 一圈一圈同时铺开 |
| 数据结构 | 栈（或递归） | 队列 |
| 找最短路径 | ❌ 不保证 | ✅ 保证（无权图） |
| 典型用途 | 连通分量、拓扑排序、找环、回溯 | 最短路径、按层遍历 |

**DFS 找到的路径不一定是最短**——它只保证「找到一条能到的路」。本例中 `DFSFindPath` 恰好也返回 `[A B D E G]`（最短），是因为这张图比较小；换一个有「绕远分支」的图，DFS 就可能先钻进远路再绕回，找到的路径就比 BFS 长了。
