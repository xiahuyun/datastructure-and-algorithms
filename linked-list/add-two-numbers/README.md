# 2. 两数相加（Add Two Numbers）

> https://leetcode.cn/problems/add-two-numbers/description/

## 题目描述

给出两个**非空**链表，表示两个非负整数。数字按**逆序**存储，每个节点存一位数字。
将两数相加，返回同样逆序存储的结果链表。

```
输入: (2 -> 4 -> 3) + (5 -> 6 -> 4)    即 342 + 465
输出: 7 -> 0 -> 8                       即 807
```

## 思路：链表上的竖式加法

逆序存储是题目的"善意"设计：**头节点恰好是个位**，顺着链表走就是从低位加到高位，
与手算竖式的顺序完全一致；两个数长度不等也不需要对位补零。

算法三要素：

| 要素 | 说明 |
|---|---|
| 两个指针 | 同步前移，较短的链表走完后按 0 参与运算 |
| 进位 carry | 每轮 `sum = carry + l1.Val + l2.Val`，本位写 `sum % 10`，`carry = sum / 10` |
| 循环条件 | `l1 != nil \|\| l2 != nil \|\| carry != 0`，任一成立就继续 |

两个关键点：

1. **循环条件必须带上 `carry != 0`**：最高位的进位要凭空多出一个节点（`99 + 1 = 100`），
   漏掉它是最常见的错误答案。
2. **哑节点（dummy）**：统一结果头节点的构建，免去对第一个节点的特殊处理。

## 为什么不能转成整数再相加

题目约束每个链表最多 100 个节点，即数字可达 `10^100`，远超 int64 上限（约 `9.2 * 10^18`）。
本题实际考察的是**用链表实现大数加法**，`main_test.go` 中的边界用例（100 位全 9）验证了这一点。

## 复杂度

- 时间：`O(max(m, n))`，每个节点恰好访问一次
- 空间：`O(1)` 额外空间（结果链表本身 `O(max(m, n) + 1)`，通常不计入）

## 运行与测试

```bash
go run main.go   # 演示输出
go test -v       # 单元测试
```

测试覆盖的用例：

- LeetCode 三个官方示例（342+465、0+0、9999999+9999）
- 两链表长度不等（99+1）
- 最高位进位，结果多一个节点（999+1=1000）
- 100 个节点的边界大数（两个 `10^100 - 1` 相加，全链进位 + 结果 101 个节点）
